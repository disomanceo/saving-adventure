# Saving Adventure School

เว็บ React/Vite สำหรับโปรเจกต์ Firebase `saving-adventure-school`

## คำสั่งหลัก

```powershell
npm install
npm run dev
npm run build
npm run deploy
```

## Firebase

- Project ID: `saving-adventure-school`
- Hosting URL: https://saving-adventure-school.web.app
- Hosting public directory: `dist`

## GitHub

หลังสร้าง GitHub repository แล้ว ให้เพิ่ม remote:

```powershell
git remote add origin https://github.com/<username>/<repo>.git
git branch -M main
git push -u origin main
```
